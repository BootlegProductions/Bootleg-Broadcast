# Holiday programming

All times use Europe/London. No backend is required.

| Event | Placement |
| --- | --- |
| Valentine | 14 February |
| St Patrick | 17 March |
| Easter | Western Easter Sunday, recalculated each year |
| Thanksgiving | US Thanksgiving: fourth Thursday of November |
| New Year | 31 December and 1 January |
| Christmas | December rotation; spotlight on 24, 25 and 26 December |

The 2026 monthly files are rotation inputs; the timed planner evaluates the actual UK year. 2027 Easter is 28 March, and 2027 US Thanksgiving is 25 November. Date previews use the current UK year. Generic seasonal movies keep their wider theme windows; dedicated holiday episodes use annual date eligibility. Adult titles remain in their late-night windows. The source catalogue shows these rules under File and seasonal fit.

Calendar references: [UK holiday calendar](https://www.timeanddate.com/holidays/uk/easter-sunday) and [US federal holiday calendar](https://www.opm.gov/policy-data-oversight/pay-leave/federal-holidays/).
