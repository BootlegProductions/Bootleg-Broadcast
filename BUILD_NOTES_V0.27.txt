Bootleg Broadcast v0.27 — Curated Schedule & CRT Display Repair

DISPLAY
- Moved tuning, backup-source and no-signal messages into the centre of the CRT.
- Removed the modern bordered notification-card appearance.
- Recoloured messages as subdued phosphor/off-white television OSD text.
- Removed every rotation from the programme Guide.
- Enlarged the Guide, headings, programme titles and status markers for legibility.

TRAILER PARK BOYS
- Removed the dead legacy Trailer Park Boys source from active scheduling.
- Removed every incorrectly paired v0.25 fallback, including S8-S12 entries that
  did not have a supplied matching replacement episode.
- Inspected the Archive item metadata and excluded DVD menus, chapter fragments,
  combined-disc tracks and short extras.
- Built a verified 55-episode S1-S7 rotation from full-length episode files.
- Added five full-length specials/films.
- Added alternates only where the supplied files genuinely represent the same
  special, rather than matching unrelated season/episode numbers.
- Rebuilt all 614 existing TPB schedule slots with the verified rotation.
- Confirmed the two TPB episodes scheduled on September 19 return HTTP 200.

SCHEDULES
- Removed the 12,289-item v0.25 bulk insertion layer and its generated advert
  breaks from active schedules.
- Preserved the extracted links in programme-library.json rather than throwing
  the supplied collections away.
- Added a restrained, show-balanced rotation of one library programme per
  channel/day, allowing new collections into the Broadcast without overwhelming
  each existing daily schedule.
- Kept October and December free of the general rotation so their dedicated
  seasonal scheduling remains intact.
- Included tools/rebuild_schedules.py so the schedule policy is documented and
  repeatable.

PLAYBACK
- Failed programmes retry once and then try genuine attached alternates.
- If every source fails, the player now skips directly to another programme
  rather than treating the following advert break as successful playback.
- Three consecutive programme failures stop the loop and leave a visible
  NO SIGNAL / CHANGE CHANNEL message.
- Pressing A now shows whether a backup exists directly on the television.

All JSON files, local idents and JavaScript syntax are validated before release.
